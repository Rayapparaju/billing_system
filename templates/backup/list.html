To enable daily auto-backups, add this cron job (Linux) or Task Scheduler (Windows):

# Run daily at 2 AM (Linux cron)
0 2 * * * cd /path/to/billingsystem && python manage.py backup_data

# Windows Task Scheduler equivalent:
python manage.py backup_data
